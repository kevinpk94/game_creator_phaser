
# Game Creator 2D

Dự án này sử dụng Vue.js và Phaser để xây dựng công cụ tạo game 2D với các tính năng:
- Thiết kế tile map
- Thêm nhân vật và di chuyển
- Thêm chướng ngại vật
- Export ra game 2D hoàn chỉnh

## Khởi động dự án

```bash
npm install
npm run dev
```

## Công nghệ sử dụng
- [Vue.js](https://vuejs.org/)
- [Phaser](https://phaser.io/)

## Hướng dẫn phát triển
- Chỉnh sửa các file trong `src/` để phát triển tính năng.
- Tích hợp Phaser vào các component Vue để render game.

## Ghi chú
- Đây là bản khởi tạo, các tính năng sẽ được bổ sung tiếp theo.
